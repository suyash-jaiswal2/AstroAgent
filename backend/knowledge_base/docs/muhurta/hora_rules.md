# Hora (Planetary Hour) Rules

Each hour of the day is ruled by a planet in a fixed sequence. The first hora of Sunday is ruled by the Sun; Saturday by Saturn; Friday by Venus; Thursday by Jupiter; Wednesday by Mercury; Tuesday by Mars; Monday by the Moon.

Sequence after sunrise: Sun, Venus, Mercury, Moon, Saturn, Jupiter, Mars (then repeats).

Auspicious horas: Jupiter hora (wisdom, expansion, teaching, spiritual matters), Venus hora (arts, romance, beauty, luxury), Mercury hora (trade, communication, contracts, intellectual work).

Neutral to positive: Moon hora (emotions, public, travel, nurturing activities), Sun hora (authority, government matters, leadership decisions).

Challenging horas: Mars hora (conflict, surgery, courage-requiring tasks), Saturn hora (delays, hard work, service, discipline required). Mars hora can be used intentionally for competitive and martial activities.
